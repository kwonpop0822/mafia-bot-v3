# Mafia Bot v3

**Mafia Bot v3**는 텔레그램 개인 채팅에서 동작하는 한국어 마피아 게임 봇입니다. 기존의 AI 봇 성격, 특수 직업, 밤 행동, 낮 투표, 유령 채팅, 랜덤 사건을 유지하면서, v3에서는 **SQLite 기반 영구 전적·포인트 랭킹·게임 기록·로비 관리·방장 권한 검증·역할 안내·재대결**을 추가했습니다.

> 봇 토큰과 개발자 비밀번호는 절대 저장소에 커밋하지 마세요. `.env.example`은 값의 형식만 보여 주는 예시입니다.

## 주요 기능

| 구분 | 제공 기능 |
|---|---|
| 게임 진행 | 마피아, 시민, 경찰, 의사, 기자, 정치인, 건달, 영매, 테러리스트, 광고자 역할과 밤/낮 사이클 |
| AI 참가자 | 성격 기반 AI 봇 추가, 자동 야간 행동, 토론·투표 참여 |
| 영구 전적 | 인간 플레이어의 완료 게임, 승·패, 진영별 승리, 포인트를 SQLite에 기록 |
| 랭킹·기록 | `/profile`, `/rank`, `/history`로 개인 전적·상위 10명·최근 게임 확인 |
| 로비 운영 | 방 목록, 방 정보, 대기 로비 퇴장, 방장 강퇴, AI 일괄 추가, 재대결 |
| 권한·안정성 | 방장 전용 설정 및 시작 권한, 입력값 검증, 예외 로깅, 방 상태 스냅샷 |
| 설정 | 대기 로비에서 랜덤 사건을 켜거나 끌 수 있음 |

## 빠른 시작

다음 예시는 Linux 및 macOS 셸 기준입니다. Windows에서는 환경변수 설정 방법만 운영체제에 맞게 바꾸면 됩니다.

```bash
git clone https://github.com/<your-account>/mafia-bot-v3.git
cd mafia-bot-v3
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_TOKEN='BotFather에서_받은_토큰'
export MAFIA_DEV_PASSWORD='강한_개발자_비밀번호'
python mafia_bot.py
```

봇이 실행되면 텔레그램에서 봇과의 **개인 채팅**을 시작한 뒤 `/start`를 입력하세요. 참가자도 봇을 먼저 시작해야 개인 메시지로 직업과 투표 버튼을 받을 수 있습니다.

## 환경 변수

| 변수 | 필수 | 설명 | 기본값 |
|---|---:|---|---|
| `TELEGRAM_TOKEN` | 예 | Telegram Bot API 토큰 | 없음 |
| `MAFIA_DEV_PASSWORD` | 권장 | `/sudo` 개발자 명령어용 비밀번호 | 코드 내 기본값 — 운영 시 반드시 교체 |
| `MAFIA_DATA_DIR` | 아니오 | SQLite 데이터 파일을 둘 디렉터리 | `data` |
| `LOG_LEVEL` | 아니오 | `DEBUG`, `INFO`, `WARNING`, `ERROR` | `INFO` |

`.env.example`을 복사해 참고할 수 있지만, 현재 코드는 환경변수를 직접 읽습니다. 쉘 환경, Docker secrets, systemd `EnvironmentFile` 등 배포 환경에 맞는 방식으로 주입하세요.

| `/연동 코드`, `/link 코드` | 계정 연동 그룹 설정 |

## 포인트 및 기록 방식

게임이 정상 종료되면 인간 플레이어만 영구 전적에 기록됩니다. 승리 시 **15점**, 패배 시 **4점**, 게임 종료 시 생존한 플레이어는 **추가 2점**을 받습니다. 게임마다 역할, 소속 진영, 승패, 생존 여부와 하이라이트가 함께 저장됩니다. AI 봇의 전적은 랭킹에 포함되지 않습니다.

SQLite 파일은 기본적으로 `data/mafia_v3.sqlite3`에 만들어집니다. 이 디렉터리는 `.gitignore`로 제외되어 있으므로, 운영 데이터는 별도 백업 정책으로 관리하세요.

## 운영 주의 사항

첫째, 이 봇은 메모리에 진행 중인 방을 유지합니다. v3는 운영 진단을 위해 방 상태 스냅샷을 SQLite에 남기지만, **진행 중인 게임을 프로세스 재시작 후 자동 재개하지는 않습니다**. 배포 전 재시작 정책을 정하고, 진행 중인 게임이 없을 때 업데이트하는 방식을 권장합니다.

둘째, `/sudo` 명령어는 개발 및 테스트 목적으로 남아 있습니다. 반드시 `MAFIA_DEV_PASSWORD`를 강한 값으로 설정하고, 신뢰할 수 없는 환경에서는 해당 기능을 제거하거나 별도 관리자 ID 검증을 추가하세요.

셋째, 텔레그램 사용자는 봇과 개인 채팅을 먼저 시작해야 직업 배정, 야간 행동 버튼, 결과 알림을 정상적으로 받을 수 있습니다.
